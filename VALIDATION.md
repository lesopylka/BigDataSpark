# Контейнерная проверка

Дата проверки 13 ноября 2026.

[Успешный прогон GitHub Actions](https://github.com/lesopylka/BigDataSpark/actions/runs/43434841252).

Проверены сборка образов, загрузка 10000 продаж в PostgreSQL, снежинка, шесть реальных витрин ClickHouse и повторный ETL. Топы, средние и временные показатели сверены с CSV.

Контрольные значения после каждого расчета или повторной доставки

- 10000 уникальных продаж
- 54623 единицы товара
- Сумма 2529852.12

Исходные файлы содержат по 1000 строк, всего 10 CSV. Сборка и проверка выполняются на чистом Ubuntu runner через Docker Compose, без подмены сервисов. Команды воспроизводятся из [.github/workflows/integration.yml](.github/workflows/integration.yml).

Дополнительно проверена миграция старой широкой таблицы товаров в PostgreSQL 16.2. Две последовательные миграции сохранили все факты. В новой модели 3 категории и 383 бренда, у товаров проверены внешние ключи.

JDBC-драйвер включен в Docker-образ. Runtime-загрузка через недоступный пользователю Ivy-кеш устранена. Дополнительные необязательные NoSQL базы в эту работу не входят.
